## Download Notes

- DigiKey's AM2302 HTML page and some Analog/ST pages were not reliably downloadable from this environment, so the report archives downloadable vendor or reputable mirror documents instead.
- Do not treat a small HTML access-denied page saved with a `.pdf` extension as a valid datasheet. Check file headers when replacing these files.
